# SECOND DRAFT — THE FAILED INVENTION

The site is now built around one story: a bizarre backyard-built flying prototype that failed, was abandoned, and is being rebuilt in real time.

### Locked art direction
- Procedural Three.js failed-invention aircraft, no pitch-deck images.
- Scroll-driven camera choreography: front, high, side, underside, orbit, pullback.
- Scroll also changes the machine: broken wings settle, repair arms enter, diagnostic ring spins, engines wake, propeller accelerates.
- Lenis smooth scrolling + GSAP ScrollTrigger.
- ReactBits `TextHoverEffect` used as a large interactive hero treatment and final CTA treatment.
- Problem / process / archive / case / submission sections are editorial, not screenshots.
- Phineas & Ferb influence is intentionally indirect: backyard invention energy, overbuilt prototype, impossible machine, hand-built workshop feel. No characters or show assets are used.

Run with:

```bash
npm install
npm run dev
```
